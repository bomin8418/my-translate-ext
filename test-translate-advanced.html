Complex Punctuation Tests

1. Semicolon-separated list

Apple; Banana; Cherry; Date; Elderberry

预期
合并为 1 单元，LLM 收到: Apple; Banana; Cherry; Date; Elderberry

2. Semicolon with final "and"

Task A; Task B; Task C; and Task D

预期
合并为 1 单元，LLM 收到: Task A; Task B; Task C; and Task D

3. Parentheses (inline)

The project (frontend) and its counterpart (backend) must be aligned.

预期
"project (frontend)" 在同一 `

` 下应合并，括号文本保留

4. Em-dash separator

Monday — Wednesday — Friday

预期
合并为 1 单元，LLM 收到: Monday — Wednesday — Friday

5. Mixed separators (comma + and + colon)

Login, Register, Settings: Profile and Security

预期
合并为 1 单元，LLM 收到: Login, Register, Settings: Profile and Security

6. Unicode symbols (bullet / arrow)

Design • Develop • Test → Deploy

预期
合并为 1 单元，LLM 收到: Design • Develop • Test → Deploy

7. Slash-separated options

Choose your role: Admin / Editor / Viewer

预期
合并为 1 单元，LLM 收到: Choose your role: Admin / Editor / Viewer

8. Pipe-separated inline

CPU | Memory | Disk | Network

预期
合并为 1 单元，LLM 收到: CPU | Memory | Disk | Network

9. Mixed Chinese + English inline

启动 the server, then 打开 the dashboard.

预期
中文文本被过滤（无字母），"server" 和 "dashboard" 被合并

10. Nested brackets

Refer to Section 3.2 (see Appendix A) for details.

预期
"3.2" 和 "Appendix A" 合并为 1 单元，LLM 收到: 3.2 (see Appendix A)

11. Long list (should NOT merge into one unit)

Alpha, Bravo, Charlie, Delta, Echo, Foxtrot, Golf, Hotel, India, Juliet, Kilo, Lima, Mike, November, Oscar, Papa, Quebec, Romeo, Sierra, Tango, Uniform, Victor, Whiskey, X-ray, Yankee, Zulu

预期
超出 MAX_CHUNK_LENGTH 时自动切分为多个单元

12. Inline-to-block transition

Quick summary:

This block explains the architecture in detail and requires a separate translation unit.
预期
"Quick summary:" 合并为 1 行内单元；下方 block 独立为 1 块级单元
