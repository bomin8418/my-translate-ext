# 2026-08-12

## 修复双语翻译模式中英文混杂 Bug

**根因**: `entrypoints/content.ts` 中 `translateAndInsert()` 的 `INLINE_THRESHOLD=60` 使强调元素（`<strong>` 等）内的短文本走行内译文，译文与后续正文同行显示；且行内译文未继承 font-weight/font-style/text-decoration。

**修改内容**（唯一文件: `entrypoints/content.ts`）:

1. **新增 `EMPHASIS_TAGS` 常量** (L74-77): `Set(['STRONG','EM','B','I','U','H1'...'H6'])`
2. **`isInline` 判定加强** (L1134): 增加 `&& !EMPHASIS_TAGS.has(anchorTag)` 条件，强调元素内文本强制块级
3. **块级插入位置上移** (L1172-1179): inline 父元素内的块级容器插入到父元素之后，避免 `<div>` 嵌 `<strong>`
4. **行内容器字体样式继承**: `createInlineTranslationContainer` 签名改为 `InlineStyleOptions`，传入 fontWeight/fontStyle/textDecoration；`getInlineTranslationStyles` 增加 CSS 变量引用
5. **调用处传参**: 从 `anchorParent.getComputedStyle()` 取值，默认值（400/normal/none）跳过传递

**验证**: `tsc --noEmit` 零错误。WXT build 被沙箱 safe-delete 拦截（环境限制），用户终端运行 `npm run build` 即可。
